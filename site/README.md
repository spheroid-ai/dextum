# DEXTUM local publication edition

Open `dist/index.html` or serve `dist/` locally. Figures read explicitly admitted
frozen reports through `read_scorecards.py`; run `python3 build_assets.py` to
rebuild. The original media are already packaged with their provenance.

No simulator, statistical re-analysis or CPU experiment is run by this build.
The full release inventory and pending freeze items are in the parent README.
